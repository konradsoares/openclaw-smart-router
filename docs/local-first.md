# Local-first cost policy

Local patch: 0.3.2-beta.2-local.1.

- `!route` remains required; ordinary messages still use the main agent.
- Self-contained prompts up to 6000 characters, including multiline prompts, prefer PAIR.
- Tool/context requests require `!route !cloud <request>` by default. The keyword heuristic is not a capability or safety guarantee.
- `allowCloudFallback` defaults to false. Set true only to authorize automatic cloud routing and local-error fallback.
- `!route !pair <request>` forces local with no plugin fallback.
- PAIR's own `model.fallbacks` must also be empty to prevent hidden paid requests.
- Local inference errors do not retry paid inference by default. Explicit cloud still uses the main agent and can incur costs.
- Run `python3 scripts/backup.py` BEFORE each future edit/update. Backups include potentially sensitive configuration and stay private under `~/openclaw-backups/smart-router`.

## Memory and continuity

Daily notes already record project decisions. They are not a response cache and are not currently loaded by the router. Each routed call still uses an isolated session. Importing the entire main transcript into a 4B model would waste context and risk overflow. Future continuity should retrieve only relevant local notes and retain provenance; do not treat cached answers as current facts or replay actions. Merging results into the originating OpenClaw transcript requires a supported session API, not direct database edits.

## Free external inference

No web-chat scraping or third-party adapter is enabled. A provider-specific supported API with documented quotas is preferable to browser automation. Before adding one, establish the provider/account, supported automation, allowed data, quota handling and session-delivery contract. Respect quota exhaustion rather than rotating accounts or bypassing limits. PAIR remains first priority; never send personal memory to public chats automatically.
